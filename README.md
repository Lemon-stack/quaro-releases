# Quaro

Downloads for Quaro, a macOS app.

## Download

**[Download the latest Quaro for macOS](https://github.com/Lemon-stack/quaro-releases/releases/latest/download/quaro_latest.dmg)**

- One universal build for both Apple Silicon and Intel Macs
- Signed and notarized by Apple

## Install

1. Open the downloaded `.dmg`.
2. Drag **Quaro** into **Applications**.
3. Launch Quaro from Applications.

Older versions are on the [Releases](https://github.com/Lemon-stack/quaro-releases/releases) page.
